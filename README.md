# College Event Registration System

## About the Project

This is a C programming project developed to manage student registrations for college events.

## Features

- Register students
- View all registered candidates
- Search candidates using registration ID
- Display the total number of registered candidates
- Check registration capacity

## Technologies Used

- C Programming
- Code::Blocks

## Concepts Practised

- Structures
- Arrays
- Functions
- Loops
- Conditional statements

## Learning Outcome

This project helped me practise organizing data using structures, working with arrays, and dividing a program into functions.
